Der Schutz deiner persönlichen Daten ist uns wichtig. Wir behandeln deine personenbezogenen Daten vertraulich und entsprechend den geltenden Datenschutzvorschriften, insbesondere der Datenschutz-Grundverordnung (DSGVO).

2. Besuch der Website

Beim Aufrufen unserer Website werden durch den Hosting-Anbieter GitHub bzw. GitHub Pages technisch notwendige Daten verarbeitet.

Dazu kann insbesondere die IP-Adresse des Besuchers gehören. GitHub gibt an, dass bei einem Besuch einer GitHub-Pages-Website die IP-Adresse zu Sicherheitszwecken protokolliert und gespeichert wird.

Die Verarbeitung dient insbesondere der Bereitstellung, Stabilität und Sicherheit der Website sowie der Abwehr von Missbrauch und Angriffen.

Weitere Informationen zum Datenschutz bei GitHub findest du in der Datenschutzerklärung von GitHub .

3. Bewerbungsformular

Auf unserer Website besteht die Möglichkeit, sich für eine Position bzw. Tätigkeit innerhalb unseres Discord-Servers zu bewerben.

Wenn du das Bewerbungsformular ausfüllst, können folgende personenbezogene Daten verarbeitet werden:

  • Discord-Name
  • E-Mail-Adresse, sofern du diese freiwillig angibst
  • Vor- bzw. Nachname
  • Alter
  • gewünschter Bewerbungsbereich
  • gewünschter Aktivitätsbereich
  • Angaben zur eigenen Aktivität
  • Begründung für die Bewerbung
  • weitere freiwillige Angaben

Die Angabe der E-Mail-Adresse ist freiwillig. Wenn du sie nicht angibst, hat dies grundsätzlich keinen Einfluss auf die Möglichkeit, dich zu bewerben.

5. Zweck der Verarbeitung

Die von dir im Bewerbungsformular eingegebenen Daten werden ausschließlich dazu verwendet,

  • deine Bewerbung zu bearbeiten,
  • deine Eignung für die gewünschte Position zu beurteilen,
  • dich bezüglich deiner Bewerbung zu kontaktieren, sofern du Kontaktdaten angegeben hast,
  • die Bewerbung innerhalb des zuständigen Server-Teams zu bearbeiten.

Die Daten werden nicht für Werbung oder Tracking verwendet.

Die Bewerbungsdaten werden gelöscht, sobald sie für die Bearbeitung der Bewerbung nicht mehr benötigt werden, sofern keine gesetzlichen Aufbewahrungspflichten entgegenstehen.

Die von dir eingegebenen Bewerbungsdaten werden an die für die Bearbeitung der Bewerbungen zuständigen Personen innerhalb unseres Teams weitergegeben.

Soweit für die Übermittlung oder Speicherung der Bewerbungsdaten ein externer Dienst eingesetzt wird, kann eine Verarbeitung durch diesen Dienstleister erfolgen. In diesem Fall muss der jeweilige Dienst in dieser Datenschutzerklärung entsprechend berücksichtigt werden.

5. Speicherdauer

Wir speichern Bewerbungsdaten nur so lange, wie dies für die Bearbeitung der Bewerbung erforderlich ist.

Wird eine Bewerbung abgelehnt oder zurückgezogen, werden die Daten gelöscht, sobald sie für die Bearbeitung nicht mehr benötigt werden, sofern keine gesetzlichen Aufbewahrungspflichten entgegenstehen.

Die Bereitstellung personenbezogener Daten im Bewerbungsformular erfolgt grundsätzlich freiwillig.

Bitte beachte jedoch, dass bestimmte Angaben erforderlich sein können, damit wir deine Bewerbung bearbeiten können.

Freiwillige Angaben müssen nicht gemacht werden.
